# Function: fromPercentage()

```ts
function fromPercentage(from, parentSize): number;
```

Converts a percentage into pixels.

## Parameters

| Parameter    | Type     | Description                                          |
| ------------ | -------- | ---------------------------------------------------- |
| `from`       | `number` | The percentage.                                      |
| `parentSize` | `number` | The size of the parent the percentage is related to. |

## Returns

`number`
