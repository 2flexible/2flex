# Function: inRange()

```ts
function inRange(
   value,
   great,
   less
): boolean;
```

Tells whether a number is between two limits.

## Parameters

| Parameter | Type     | Description                            |
| --------- | -------- | -------------------------------------- |
| `value`   | `number` | The number that is checked.            |
| `great`   | `number` | The smallest number the result can be. |
| `less`    | `number` | The biggest number the result can be.  |

## Returns

`boolean`
