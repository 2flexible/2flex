# Function: hexToRgba()

```ts
function hexToRgba(hex): string;
```

Converts a hexadecimal color into a color with an alpha channel.

## Parameters

| Parameter | Type     | Description                       |
| --------- | -------- | --------------------------------- |
| `hex`     | `string` | The color, for example `#ff0000`. |

## Returns

`string`
