# Function: fromRem()

```ts
function fromRem(from, parentSize): number;
```

Converts a value of the root font size into pixels.

## Parameters

| Parameter    | Type     | Description                |
| ------------ | -------- | -------------------------- |
| `from`       | `number` | The value.                 |
| `parentSize` | `number` | The size of the root font. |

## Returns

`number`
