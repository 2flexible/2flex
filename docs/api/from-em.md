# Function: fromEm()

```ts
function fromEm(from, parentSize): number;
```

Converts a value of the font size into pixels.

## Parameters

| Parameter    | Type     | Description           |
| ------------ | -------- | --------------------- |
| `from`       | `number` | The value.            |
| `parentSize` | `number` | The size of the font. |

## Returns

`number`
