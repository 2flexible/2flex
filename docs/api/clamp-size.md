# Function: clampSize()

```ts
function clampSize(value): number;
```

Keeps the size of a block at a value that can be drawn.

## Parameters

| Parameter | Type     | Description            |
| --------- | -------- | ---------------------- |
| `value`   | `number` | The size that is kept. |

## Returns

`number`
