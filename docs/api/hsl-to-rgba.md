# Function: hslToRgba()

```ts
function hslToRgba(hsl): string;
```

Converts a color of the hsl space into a color with an alpha channel.

## Parameters

| Parameter | Type     | Description                                 |
| --------- | -------- | ------------------------------------------- |
| `hsl`     | `string` | The color, for example `hsl(0, 100%, 50%)`. |

## Returns

`string`
