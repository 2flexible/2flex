# Function: fromVH()

```ts
function fromVH(from, parentHeight): number;
```

Converts a percentage of the height of the viewport into pixels.

## Parameters

| Parameter      | Type     | Description                 |
| -------------- | -------- | --------------------------- |
| `from`         | `number` | The percentage.             |
| `parentHeight` | `number` | The height of the viewport. |

## Returns

`number`
