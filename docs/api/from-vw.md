# Function: fromVW()

```ts
function fromVW(from, parentWidth): number;
```

Converts a percentage of the width of the viewport into pixels.

## Parameters

| Parameter     | Type     | Description                |
| ------------- | -------- | -------------------------- |
| `from`        | `number` | The percentage.            |
| `parentWidth` | `number` | The width of the viewport. |

## Returns

`number`
